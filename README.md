# NeuralChat - Multi-Agent AI Chatbot - https://neuralchat-multi-agent-1.vercel.app/

NeuralChat is a full-stack Multi-Agent AI chatbot system designed to process user queries through a structured pipeline of intelligent agents. Instead of relying on a single AI model, this system uses multiple specialized agents working together to generate accurate and refined responses.

---

## 🚀 Features

- 🤖 Multi-Agent Architecture (5 Agents)
- 🔄 Sequential Processing Pipeline
- ⚡ Real-time Response Streaming (SSE)
- 🌐 Full Stack Application (React + Node.js)
- 🔑 Groq API Integration (LLM support)
- 🔒 Secure Backend (Rate limiting, CORS)
- ☁️ Deployed on Vercel

---

## 🧠 How It Works

User input is processed through a chain of agents:

User Input → Understanding Agent → Processing Agent → Reasoning Agent → Response Agent → Formatter → Final Output

Each agent performs a specific task, improving the overall quality and structure of the response.
